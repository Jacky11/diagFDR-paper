# Figures

Figures 3, 4 and 5 are generated by `make_figures.R` from the universes written by
`real_data/02_import_diann.R` and `real_data/06_msrescore.R`; every curve and
number is computed with the exported functions of `diagFDR` (>= 0.2.1). Figures 1
and 2 are drawn by hand in PowerPoint (`manuscript/figures/Figure1.pptx`,
`Figure2.pptx`); the report captured in Figure 2B is regenerated here.

```
cd figures
Rscript make_figures.R            # -> out/Figure{3,4,5}.pdf / .png / .pptx + *_values.csv
Rscript figure2B_report.R         # runs dfdr_run_all() on three lists of the basic search, renders the HTML report
python figure2B_screenshots.py    # Playwright + Chromium captures of title, TOC, executive summary, headline table
python figure2B_update_pptx.py ../../manuscript/figures/Figure2.pptx out/Figure2.pptx
```

`make_figures.R` needs ggplot2, patchwork, officer, rvg, scales and ragg. Each
`.pptx` holds one slide the size of the figure with every panel as native
PowerPoint shapes (ungroup once to edit a label); the `.pdf` is vector and the
`.png` is 300 dpi. The `*_values.csv` files hold the numbers behind each panel and
`figures_provenance.txt` the package version used. Figure 4 includes the
semi-tryptic first-pass series only when `report_semi-first-pass.parquet` is present.
